# تطبيق متجر رواسي

تطبيق لإدارة متجر رواسي، ويشتغل على الموبايل والحاسبة:

- **المخزن:** حسب وجبات التجهيز، والكلفة تنحسب بطريقة FIFO.
- **الشراء بالتومان:** كل وجبة تنحفظ بسعر صرف يومها.
- **الحجوزات:** تنرتب حسب الأسبقية، وتقدر تعطي خصم على قطعة أو على الحجز كله.
- **الدفعات:** نزلات الإنستقرام، وكل دفعة تبين شكد انباع منها وشكد باقي.
- **التقارير والمصاريف.**
- **رفع وتصدير إكسل.**
- **مساعد ذكي.**

**رابط التطبيق:** https://ghraoy.github.io/rawasi/

> **أين تنحفظ البيانات؟** على جهازك أولاً، فالتطبيق يشتغل حتى بدون إنترنت. وبعد الإعداد تحت، تنحفظ نسخة بالـ Google Drive مالتك. المستودع على GitHub فيه كود التطبيق فقط، وما بيه أي بيانات من بياناتك.

---

## 1. تنزيل التطبيق على الموبايل

**أندرويد (Chrome):**
1. افتح الرابط.
2. اضغط القائمة ⋮.
3. اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق**.

**آيفون (Safari):**
1. افتح الرابط.
2. اضغط زر المشاركة.
3. اختر **إضافة إلى الشاشة الرئيسية**.

**الحاسبة:** افتح الرابط بـ Chrome، واضغط أيقونة التثبيت بشريط العنوان.

---

## 2. ربط Google Drive (مرة وحدة، تقريباً 10 دقائق)

سوّ هذه الخطوات وأنت مسجل بحساب **cfg44dfr@gmail.com**.

1. افتح https://script.google.com واضغط **New project** (مشروع جديد).
2. احذف الموجود، والصق كل محتوى الملف [`apps-script/Code.gs`](apps-script/Code.gs).
3. بأول السكربت غيّر هذا السطر:
   ```js
   const TOKEN = 'اكتب-هنا-رمز-سري-طويل';
   ```
   اكتب بداله رمز سري من اختيارك، مثلاً `rawasi-2026-najaf-91x7`. لا تشاركه مع أحد.
4. اضغط 💾 للحفظ، وسمّ المشروع "رواسي".
5. من القائمة فوق اختر الدالة **setup**، واضغط **Run** (تشغيل). Google راح يطلب صلاحيات Drive و Sheets، فوافق:
   - اختر حسابك.
   - اضغط **Advanced** (متقدم).
   - اضغط **Go to رواسي (unsafe)**.
   - اضغط **Allow**.

   هذا طبيعي لأن السكربت مالتك أنت.
6. اضغط **Deploy ← New deployment** (نشر ← نشر جديد):
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy**، وانسخ **Web app URL**. الرابط ينتهي بـ `/exec`.
7. بالتطبيق افتح **المزيد ← الإعدادات ← المزامنة**:
   - الصق الرابط.
   - اكتب نفس الرمز السري.
   - اضغط **حفظ واختبار**.

بعد هذا، التطبيق يسوي مجلد بالـ Drive اسمه **"رواسي - بيانات التطبيق"**، وبيه:
- `rawasi-data.json`: البيانات الكاملة.
- **رواسي - الجداول**: Google Sheet تقدر تفتحه وتقرأ فيه المخزن والحجوزات والوجبات والمصاريف.
- **نسخ احتياطية**: نسخة كل يوم، ويحتفظ بآخر 30 يوم.

> إذا عدّلت السكربت بعدين، لازم تسوي **Deploy ← Manage deployments ← ✏️ ← Version: New version** حتى يشتغل التعديل، والرابط يبقى نفسه.

## 3. تفعيل المساعد الذكي (اختياري)

1. افتح https://aistudio.google.com/apikey بنفس الحساب، واضغط **Create API key**، وانسخ المفتاح.
2. بالسكربت حط المفتاح هنا:
   ```js
   const GEMINI_KEY = 'المفتاح هنا';
   ```
3. احفظ، وسوّ **New version** مثل ما بالملاحظة فوق.

**الكلفة:** Google يحاسب حسب الاستخدام. السكربت يستخدم أرخص نموذج سريع (`gemini-3.5-flash-lite`)، فاستخدام متجر صغير يبقى قليل الكلفة. تقدر تتابع الاستخدام والحدود من AI Studio. المفتاح ينحفظ بالسكربت فقط، وما يوصل للتطبيق أو للمستودع.

**شنو يسوي المساعد:**
- **حجز من رسالة:** تلصق رسالة الزبون من الخاص، فيطلع منها الاسم والهاتف والمحافظة والعنوان والقطع.
- **كابشن لمنتج:** يكتب كابشن باللهجة العراقية، يبدأ بسطر مشكلة وبعده الحل، ويقدر يشوف صورة المنتج.
- **اسأل عن متجرك:** مثل "شنو أطلب للدفعة الجاية؟" أو "شنو الراكد؟".

## 4. طريقة الشغل اليومية

1. **اشتريت بضاعة؟** سجّلها من **المنتجات ← وجبات التجهيز ← +**:
   - سعر كل قطعة بالتومان.
   - سعر الصرف بيومها. وإذا ما تعرفه، اكتب كم دفعت بالدينار ويطلع الصرف لحاله.
   - مصاريف النقل والكمرك، وتنوزع على القطع.

   تقدر تسجلها من ملف إكسل بداله.
2. **راح تنشر بالإنستقرام؟** من صفحة الوجبة اضغط **دفعة نشر منها**. وبعدها من صفحة الدفعة اضغط **نسخ قائمة الأسعار** والصقها بالمنشور.
3. **إجتك رسالة حجز؟** عندك طريقتين:
   - **حجز من رسالة** (بالمساعد).
   - أو **حجز جديد** يدوياً.

   الكمية تنحجز فوراً، ورقم الأسبقية ينعطى تلقائياً.
4. **غيّر حالة الحجز:** تأكيد ← إرسال ← استلم. لما يصير "مُرسل" القطع تنخصم من المخزن، وتنحسب كلفتها من الوجبة الأقدم.
5. **التقارير:** تبين المبيعات والربح الحقيقي بعد الخصومات والمصاريف، والأكثر مبيعاً.

## للمطوّرين

تطبيق ويب ثابت (PWA): HTML و CSS و JavaScript بدون أي خطوة بناء.

- `js/logic.js`: منطق المخزن والتقارير، وفيه اختبارات `npm test`.
- `js/store.js`: التخزين المحلي والدمج.
- `js/sync.js` و `apps-script/Code.gs`: المزامنة.
- `js/ai.js`: طلبات المساعد.
- `js/views-*.js`: الشاشات.

للتشغيل محلياً: `python3 -m http.server` ثم افتح http://localhost:8000.
